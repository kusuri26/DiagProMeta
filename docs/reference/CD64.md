# Meta-analysis of diagnostic studies: CD64 data

A dataset from a meta-analysis of diagnostic studies evaluating
neutrophil CD64 expression for the early diagnosis of bacterial
infection. The dataset contains study-level 2 x 2 diagnostic accuracy
data together with information on cutoff values, measurement units, and
subgroups.

## Usage

``` r
CD64
```

## Format

A data frame with 27 rows (studies) and 11 variables:

- study:

  Study identifier.

- Author:

  Author or authors of the study.

- TP:

  Number of true positive cases.

- FN:

  Number of false negative cases.

- FP:

  Number of false positive cases.

- TN:

  Number of true negative cases.

- cutoff:

  Diagnostic cutoff value used in the study.

- unit:

  Measurement unit of the cutoff value.

- unit.grp:

  Measurement-unit group used in the study.

- cutoff.grp:

  Cutoff-value group used in the study.

- subgroup:

  Subgroup of the study used for analysis.

## Source

Li S, Huang X, Chen Z, Zhong H, Peng Q, Deng Y, Qin X, Zhao J (2013).
Neutrophil CD64 expression as a biomarker in the early diagnosis of
bacterial infection: A meta-analysis. *International Journal of
Infectious Diseases*, 17(1), e12–e23.
[doi:10.1016/j.ijid.2012.07.017](https://doi.org/10.1016/j.ijid.2012.07.017)

## Examples

``` r
data(CD64)
```
